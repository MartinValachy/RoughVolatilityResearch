# UZH reference note - superseded as a project gate

The original request asked for current thesis/AI rules. Official sources were inspected on 20 October 2026, before the user reclassified the project as independent research intended for publication. These rules are recorded for possible future reuse; they do not constrain the present project's academic registration status because no thesis is being pursued here.

- [Faculty thesis process](https://www.oec.uzh.ch/de/studies/theses.html): Bachelor thesis 18 ECTS, six-month processing period. The standard workflow starts through OLAT after a supervisor has accepted; topic selection records the binding deadline. The website delegates detailed process choices to the supervisor.
- [Department of Finance FAQ](https://www.df.uzh.ch/de/studies/studierendenleben-und-beratung/abschlussarbeiten/faq.html): generative-AI use requires a table describing tool, purpose, affected tasks/sections and the student's verification. Responsibility for correctness remains with the author.
- [HS26 transition rules](https://www.oec.uzh.ch/dam/jcr%3A7008d10c-b581-45bd-9d35-35c0ff787b43/Bachelor%20%C3%9Cberf%C3%BChrungsregeln%20SO22%20ab%20HS26_EN.pdf): alternative thesis formats are conditional on advisor/program eligibility, not an entitlement.
